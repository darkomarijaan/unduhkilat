Seberapa jauh tiap format bisa dibaca

Kemampuan berbeda-beda. Saya sebut apa adanya supaya tidak ada yang terasa dijanjikan terlalu tinggi.

FormatTampilan di dalam aplikasiTingkat
txt, md, log, json, xml, kodeTeks dengan penomoran baris; Markdown dirender (judul, daftar, tabel)Penuh
jpg, png, gif, webp, bmpGambar dengan zoom dan geserPenuh
pdfHalaman dirender sebagai gambar, bisa gulir dan zoom. Butuh menambah komponen perender PDF (±10 MB)Hampir penuh
docx, odtTeks, judul, dan tabel saja. Tanpa font asli, gambar sebaris, atau tata letak halamanTeks saja
xlsx, odsSel dan lembar sebagai tabel (nilai, bukan rumus atau grafik)Tabel saja
doc, xls, ppt, pptx, lainnyaTombol "Buka di aplikasi Windows": berkas diunduh ke folder sementara lalu dibuka dengan Word/Excel/PDF reader AndaBuka eksternal

Berkas besar tidak diunduh penuh untuk pratinjau: teks dan PDF diambil sebagian dulu, dan ada batas ukuran (misalnya 25 MB) sebelum aplikasi menawarkan "Unduh" atau "Buka di aplikasi".
